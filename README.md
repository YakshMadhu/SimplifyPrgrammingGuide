# SimplifyPrgrammingGuide

As the title suggests

**Dynamic Programming**
- Identify overlapping subproblems
- Store solved results  
**Ingredients:** subproblem states, base cases, transition rules, result storage

**Array**
- Group related values
- Access by index  
**Ingredients:** elements, indices, positions

**String**
- Represent text
- Store character sequences  
**Ingredients:** ordered characters, character positions

**Hash table**
- Associate keys with values
- Look up by key  
**Ingredients:** keys, values, hash function, collision handling

**Sorting**
- Arrange in order
- Order by criteria  
**Ingredients:** items, comparison rule, desired order

**Greedy**
- Make locally optimal choices
- Build solution incrementally  
**Ingredients:** available choices, local choice rule, constraints, stopping condition

**Binary search**
- Search the sorted data
- Halve the search range  
**Ingredients:** sorted data or monotonic range, target or condition, search boundaries, midpoint

**Depth-First Search**
- Explore one branch at a time
- Backtrack when needed  
**Ingredients:** nodes, neighbor relationships, starting node, visited tracking, stack or recursion

**Database**
- Store organized records
- Retrieve needed information  
**Ingredients:** data, storage, organization method, retrieval method

**Bit manipulation**
- Change individual bits
- Check bit values  
**Ingredients:** binary values, bit positions, bitwise operations

**Matrix**
- Organize values in rows
- Access by coordinates  
**Ingredients:** rows, columns, cells, row and column indices

**Prefix sum**
- Store running totals
- Answer range sums  
**Ingredients:** input sequence, cumulative totals, range boundaries

**Tree**
- Represent hierarchies
- Trace parent-child paths  
**Ingredients:** nodes, edges, connected structure without cycles, root if rooted

**Two pointers**
- Track two positions
- Compare or narrow ranges  
**Ingredients:** sequence or range, two indices, pointer movement rules

**Breadth-first search**
- Visit nearby nodes first
- Find minimum step paths  
**Ingredients:** nodes, neighbor relationships, starting node, queue, visited tracking

**Heap (priority queue)**
- Keep track of priorities
- Remove top priority  
**Ingredients:** items, priority rule, heap structure, insert and remove operations

**Simulation**
- Follow given rules
- Track changing states  
**Ingredients:** initial state, rules, steps or events, stopping condition

**Counting**
- Tally occurrences
- Compare frequencies  
**Ingredients:** items, categories, counters

**Graph theory**
- Model connections
- Analyze paths and cycles  
**Ingredients:** vertices, edges, directed or undirected relationships

**Stack**
- Access latest item first
- Track nested operations  
**Ingredients:** items, top position, push and pop operations

**Binary tree**
- Model two-way branches
- Give nodes two children  
**Ingredients:** nodes, left and right child links, root

**Sliding window**
- Track a continuous section
- Update as it moves  
**Ingredients:** sequence, window boundaries, add and remove rules

**Enumeration**
- Check every possibility
- Find valid choices  
**Ingredients:** candidate space, way to generate candidates, validity check

**Design**
- Define data structures
- Support required operations  
**Ingredients:** requirements, operations, stored state, rules for each operation

**Backtracking**
- Try possible choices
- Undo dead ends  
**Ingredients:** choices, partial solution, constraints, undo operation, completion check

**Union-find**
- Join connected groups
- Check group membership  
**Ingredients:** elements, group representatives, find operation, union operation

**Segment tree**
- Summarize data ranges
- Answer range queries  
**Ingredients:** indexed data, ranges, range summary, combine operation

**Linked list**
- Connect items in sequence
- Insert or remove items  
**Ingredients:** nodes, stored values, next links, head

**Monotonic stack**
- Keep values ordered
- Find next larger values  
**Ingredients:** sequence, stack, ordering rule, push and pop conditions

**Divide and conquer**
- Split into smaller problems
- Combine partial answers  
**Ingredients:** problem, splitting rule, base cases, combining rule

**Trie**
- Organize words by prefixes
- Find shared beginnings  
**Ingredients:** root, character-labeled links, end-of-word markers

**Queue**
- Process items in arrival order
- Remove oldest item first  
**Ingredients:** items, front, rear, enqueue and dequeue operations

**Bitmask**
- Represent selected options
- Store sets using bits  
**Ingredients:** items mapped to bit positions, binary value, bitwise operations

**Recursion**
- Solve smaller versions
- Stop at a base case  
**Ingredients:** function call, smaller input, base case, progress toward stopping

**Hash function**
- Produce hash values
- Help compare data  
**Ingredients:** input key, deterministic mapping, hash value

**Memoization**
- Save solved results
- Reuse repeated answers  
**Ingredients:** subproblem identifier, result cache, lookup and save operations

**Shortest path**
- Find the cheapest route
- Minimize travel cost  
**Ingredients:** graph, edge costs, starting point, destination

**Binary search tree**
- Keep values ordered
- Search by comparisons  
**Ingredients:** nodes, keys, left and right links, ordering rule

**Topological sort**
- Order prerequisites first
- Schedule dependent tasks  
**Ingredients:** directed graph, dependency edges, no directed cycles

**String matching**
- Find patterns in text
- Report matching positions  
**Ingredients:** text, pattern, character comparison rule

**Rolling hash**
- Update text hashes
- Compare text sections  
**Ingredients:** text, hash rule, window, rolling update rule

**Game theory**
- Analyze competing choices
- Choose winning strategies  
**Ingredients:** players, available moves, rules, outcomes

**Monotonic queue**
- Track window extremes
- Remove dominated values  
**Ingredients:** queue or deque, ordering rule, window boundaries, add and remove conditions

**Interactive**
- Judge questions
- Adapt to replies  
**Ingredients:** judge, allowed queries, responses, query rules, final answer

**Data stream**
- Process incoming values
- Maintain a running summary  
**Ingredients:** incoming data, current state, update rule

**Brainteaser**
- Solve logic puzzles
- Find hidden patterns  
**Ingredients:** clues, constraints, possible explanations, logical deductions

**Merge sort**
- Divide into halves
- Merge sorted halves  
**Ingredients:** sequence, split rule, base case, merge operation

**Minimax**
- Anticipate the opponent’s best move
- Protect the worst-case outcome  
**Ingredients:** players, possible moves, game tree, outcome scores

**Doubly linked list**
- Link previous and next
- Move either direction  
**Ingredients:** nodes, stored values, previous and next links

**Randomized algorithms**
- Make random choices
- Improve expected performance  
**Ingredients:** input, random source, probability rule, algorithm

**Counting sort**
- Count each value
- Rebuild values in order  
**Ingredients:** items with countable keys, manageable key range, counters, output

**Iterator**
- Move through a collection
- Access the next item  
**Ingredients:** collection, current position, next operation, end condition

**Concurrency**
- Manage overlapping tasks
- Coordinate shared resources  
**Ingredients:** tasks, execution schedule, shared resources if any, coordination rules

**Suffix array**
- Order text suffixes
- Find repeated substrings  
**Ingredients:** text, suffix starting positions, ordering rule

**Quickselect**
- Find a ranked value
- Avoid sorting everything  
**Ingredients:** collection, target rank, pivot, partition rule

**Sweep line**
- Process positions in order
- Track active intervals  
**Ingredients:** ordered events, event positions, active items, event rules

**Minimum spanning tree**
- Connect all vertices
- Minimize total connection cost  
**Ingredients:** connected undirected graph, edge weights, spanning tree

**Bucket sort**
- Group similar values
- Sort each group  
**Ingredients:** values, value ranges, groups for those ranges, order within each group

**Shell sort**
- Compare distant elements
- Shrink gaps gradually  
**Ingredients:** array, gap sequence, comparisons and moves, final gap of one

**Strongly connected components**
- Find mutual reachability
- Group mutually reachable nodes  
**Ingredients:** directed graph, vertices, edges, reachability relationships
